# DOCX–LaTeX 正文基线一致性核验

核验对象：

- 内容基线：`磁驱柔性导管_期刊投稿预备版(4)(1).docx`
- LaTeX 工程：`CHNN_KAM_Word基线完整迁移版_v2`
- 核验原则：DOCX 决定内容；LaTeX 只承担结构化迁移。实验占位内容不补写、不删减。

## 结论

本轮未发现 DOCX 正文在 LaTeX 工程中发生实质性遗漏、增写、换序或数学内容改动。当前中文 LaTeX 可以作为后续持续维护的主稿基线；原 DOCX 应保留为只读迁移档案，不再与 LaTeX 并行修改。

## 自动与人工核验结果

1. 前置内容：题名、英文题名、作者占位、摘要、关键词、英文摘要和英文关键词的规范化文本完全一致。
2. 标题结构：DOCX 与 LaTeX 的 171 个正文标题逐项对齐，层级和顺序一致。DOCX 额外包含文末“参考文献”标题，该标题由 LaTeX 文献环境生成。
3. 编号公式：双方均有 424 个显示公式，按出现顺序逐式比较全部一致。比较时仅将 Word 的 `\mathbf` 与工程语义宏 `\bm` 视为等价，并忽略 LaTeX 的 `\label`。
4. 行内数学：DOCX 提取出 605 项，LaTeX 提取出 601 项。4 项差额均为 Word 中作为行内数学保存的证明结束方块；LaTeX 由 `proof` 环境自动生成，未发现实际行内公式缺失。
5. 正文段落：按 171 个标题分区比较，去除文献编号、交叉引用的渲染编号、空白和纯排版标记后，161 个分区完全一致；其余 10 个分区的差异来自定理标题自动编号、证明环境名称、引号、占位括号和带页码的文献引用表示。逐项复核未发现内容性差异。
6. 定理环境：工程含 7 个正式环境，类型和题名与 DOCX 一致：2 个命题、2 个定理、1 个推论、1 个假设、1 个引理。证明结束符由环境自动生成。
7. 标签与引用：171 个章节标签、424 个公式标签，合计 602 个唯一标签；79 次交叉引用调用均可解析。
8. 参考文献：BibTeX 数据库含 37 条记录，正文使用 37 个唯一文献键，无未用条目和缺失条目；文献顺序由 `bibliography/order.tex` 固定为 DOCX 基线顺序。
9. 构建：XeLaTeX/BibTeX 构建成功，输出 51 页；无未定义引用、未定义文献、重复标签、缺字或盒子溢出。

## 本轮修复

- 删除无编号“引言”的重复目录写入，使目录只保留一个“引言”。
- 完善 `cleveref` 的中文 section/subsection/subsubsection 单项、多项和区间格式：
  - `第 1、2 节`
  - `第 1.4.4 节`
  - `第 3.7.3 节`
- 未改动任何正文句子、公式、标签、文献键、定理内容或实验占位。

## 基线管理建议

从本次核验通过开始：

- 中文 LaTeX 工程作为唯一可编辑内容主线；
- DOCX 冻结为迁移审计档案；
- 英文 DOCX 仅作术语和表达参考；
- 后续英文稿在同一工程内建立独立语言层，并通过自动检查保证中英文标签、公式和文献键集合一致。

## 核验边界

本次核验确认内容和数学结构一致，不要求 Word 与 LaTeX 的分页、字体和版式一致。实验结果仍按原基线保留待回填状态。
