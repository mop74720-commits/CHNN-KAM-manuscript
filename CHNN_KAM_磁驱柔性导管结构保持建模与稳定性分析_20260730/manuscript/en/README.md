# English manuscript tree

This directory contains the complete English language-layer translation of the verified Chinese baseline in `manuscript/zh/`.

The following objects must remain synchronized with the Chinese tree:

- file names and section hierarchy;
- `\label` identifiers;
- equations, figures, tables, and code assets;
- BibTeX citation keys;
- journal-neutral semantic macros;
- theorem and result-placeholder environments.

Do not place Elsevier-, Springer-, Wiley-, or other publisher-specific commands in these manuscript files. Target-journal commands belong in a separate adapter layer.
