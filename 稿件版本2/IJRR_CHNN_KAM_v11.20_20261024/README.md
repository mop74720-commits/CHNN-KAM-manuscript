本版承接 v11.19，保持 IJRR/SAGE 模板和老师要求的六部分结构。使用同一个 918 实参数复值网络权重；本轮复用已有数据和状态管进行证明、精确算术与区间验证，没有新增训练、ODE 积分或 COMSOL 求解。

对固定源二次项、零三次项、仅 A² 系数 c 变化的保守 Hamiltonian，完整 64 模态矩阵 pencil 的谱和频率配对经 320 bit 计算及 384 bit 独立复算。每个有限实 c 处，普通 twist 或其频率边框至少一个非退化。辅助能量函数 F(H)=H+H²/(2Es) 将局部 KAM 结论转回原 Hamiltonian：每个成员的任意小邻域中均有正相体积的 Diophantine Lagrangian 64 环面族。邻域可依赖 c；未给统一数值半径、指定能量层或一般 42 系数族的结论。

同一个 c∈[-10⁻¹⁵,0] 对全部 22 条有符号记录各自的保存初态与输入，同时满足首四格、共 88 格的原联合观测误差球。中心和半径保持原值；独立复算从原 MAT 重建全部 Hermite 中心。完整保存区间的源—切片连续依赖界不等于拟合全部 257 个原始采样点。这一联合可行性说明旧短窗不能唯一识别该系数，没有将观测误差球解释为已标定的物理噪声。

耗散部分新增完整节点功的精确分解，区分训练到的奇部分弱功、偶部分、窗内模态变化和投影外功。针对 saved-buffer 与 exact-source 基底分别给出精确有理数见证：弱残差可为零而完整功不为零。因此“小弱损失”本身不能提供完整安全预算；见证描述有限观测算子，不是实际物理反例轨迹。

对原全部 88 个有符号窗口，44 组 odd rows 的精确算子与实数意义下缓存公式之联合差上界 ηop<1.318083006×10⁻¹¹。该算子界保留原节点及网络绝对权重导数界，没有把 saved projection 的近似左逆当成精确恒等式。它尚未包含浮点执行与实数缓存公式之间的算术差，完整 ηO 仍需接收这一项；打印损失没有被升级为严格完整功界。

另复用已有 full-state 状态管，对正负 direction-three 两条明确源 IVP 的首四格，在 0–3.125×10⁻⁷ 秒接收连续全前缀残差功上界，分别小于 1.027949038×10⁻⁵ Enet 与 2.844323240×10⁻⁵ Enet。计算保留源阻尼与候选阻尼的区别。它不覆盖全部 22 条训练轨迹；开环输入的非正功条件尚未接收，因而不是长时或物理安全声明。

一般 42 系数族与未知物理目标的 KAM 迁移、完整执行算术接口、全部实际轨迹的全前缀功预算、磁反馈的传感与执行条件仍未完成。已有比较也没有确立一般复值网络优势。完整研究目标保持未完成。
