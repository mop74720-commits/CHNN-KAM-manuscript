# v11.19 IJRR/SAGE 封存稿

- [正式正文，30 页](main.pdf)
- [正式补充材料，93 页](supplement.pdf)
- [文件大小与 SHA-256 清单](发布清单_v11.19.json)

本版保持 IJRR/SAGE 模板及老师六部分结构，承接 v11.18 的理论、训练与验证材料，补入结构化系数接收、原生数据数值机制诊断及连续参考的严格误差接口。

现有全部七个二次系数外区间保持完整 64 坐标 Hessian 正定，相对扰动预算小于 0.000824179。另一方面，当前四阶系数外盒内存在 A² 方向的 twist 退化点，不能对整个外盒统一使用四阶 Kolmogorov 非退化判据；该见证不等于全部原轨迹联合可行的物理目标，也不证明 KAM 环面不存在。

旧正初速粗细两档 native 导出得到与线性 Cayley 离散重放一致的数值签名。它为当前差异提供数值机制证据，没有证明 COMSOL 编译方程或求解器设置等价。对明确声明的数学源 IVP，固定显式参考在整个 0–0.6 秒的归一化误差管小于 2.229×10⁻⁴；全部 96,001 个采样时刻的相位、坐标与评分舍入也已接收。

原 918 参数模型保存数值向量对该声明源精确解的采样最大误差上界，主设置小于 2.634×10⁻⁴、参考设置小于 2.856×10⁻⁴。这里比较固定保存向量，不认证学习模型的精确 IVP 解或输出点之间的行为。粗、细 native 固定导出样本对声明源的最大误差区间分别为 [0.65455849, 0.65500435]、[0.58070567, 0.58115153]；这不是物理误差或 COMSOL 精确 IVP 解的误差声明。

本轮评分复用全部 13 个冻结模型、每个模型两种积分设置，共 26 条既有预测；保留所有对照组和种子，没有为评分重训或新增积分。9/13 个模型触发预定数值敏感性标记。目前结果不支持一般复值优势，未知物理目标的 KAM 迁移、COMSOL 编译方程接口和完整研究目标仍未完成。
