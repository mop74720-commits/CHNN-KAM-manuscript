保持原 IJRR/SAGE 模板及老师的六部分结构。相对 v11.17，新增旧全场数据的法向系数接收、剩余 A² 系数的轨迹观测、完整 64 模态二/三/四阶同时误差条件、实际 31 项损失加 11 项验证约束的 KAM 连接，以及整个 Ω4 的严格候选耗散证明。

正初速 0.6 秒 COMSOL 粗细记录各一条已完成。13 个固定模型各保留两组数值设置预测，共 26 条正式档案预测；细步结果复用这些预测重评分，没有重新训练或积分。全部五项比较保留三个种子。两档原生记录的归一化全状态最大差为 0.643731731，尚未形成收敛参考；原 918 参数模型对细步记录的最大/RMS/末态误差为 0.58092591/0.50106948/0.48303912。

理论允许误差的正邻域已明确，但现有系数区间仍未进入充分容差，未知物理目标的 KAM 迁移未完成。候选耗散结论不等于物理阻尼识别。当前比较不支持普遍复值优势，负初速配对仍待完成。正式稿保留这些适用条件与结论边界。
