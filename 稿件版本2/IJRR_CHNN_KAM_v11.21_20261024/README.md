本版承接 v11.20，保持 IJRR/SAGE 模板和老师要求的六部分结构。使用同一个 918 实参数复值网络权重；本轮复用已有原始记录、状态管和数学 source 模型，新增证明、精确算术与独立区间复核，0 次新训练、ODE 积分或 COMSOL 求解。

保守部分保留固定源二次项、零三次项、仅 A² 系数 c 变化的完整 64 模态局部 KAM 结论：每个有限实 c 对应的 Hamiltonian 在任意小平衡邻域内有正相体积的 Diophantine Lagrangian 64 环面族，邻域可依赖 c。相同 c∈[-10⁻¹⁵,0] 同时满足全部 22 条有符号记录首四格的原联合观测误差球；这不等于拟合全部 257 个原采样点，不给统一数值半径，也不推广到一般 42 系数族或未知物理目标。

耗散部分完成原训练顺序的全部 88 个有符号弱窗口、44 组 odd rows 的执行算术接收。实际 binary64 弱行与原生 exact-source 数学缓存之间的联合外向界为 ηO<1.585366525×10⁻¹¹，其中 ηarith<2.672835191×10⁻¹²、ηop<1.318083006×10⁻¹¹；同一数学弱损失 LD<9.473763848×10⁻¹¹。实际打印 MSE 已逐位重现。这些量使用原弱行归一化，并非完整连续功预算。精确功分解及 saved-buffer/exact-source 两类核见证仍说明：小弱损失本身不能控制偶部分、窗内变化或投影外功。

在明确的全局标量 source 本构先验、由非零 force loss 接收的参数区间、相同完整质量与磁输入端口及正黏性下界下，source 能量比较给出每个时间前缀的残差功预算。一般定理明确要求实际输入供给 S(t)=∫uy 的每个前缀上界；该上界不能由储能 cap 代替。黏性下界是独立先验，未由弱耗散损失辨识。

对原 22 个保存数值初态定义的数学 source IVP，直接使用整条 exact-decimal cosine 输入律的幅度上界和各自原 binary64 终点，接收完整约 20 μs 有限时域的全部连续前缀。绝对输入功小于 0.096606 Enet，统一取 P=0.1；W/Enet<1.277474991512，候选储能 HN/Enet<2.349722602874。没有将原短窗状态管外推为全时域 COMSOL 误差界。

对原三段实际 held-total-field 对应的同 saved-seed source reference IVP，按 signed magnetic-work 恒等式直接接收有限区间内 S(t)≤0。原第一段 15 格瞬时非正功测试失败完整保留；累计供给非正不表示任意两时刻间单调。使用这条历史自己的初态，得到有限时域 W/Enet<1.133261675220、HN/Enet<2.133261675220。原第三传感契约失败也保留，没有推出未来反馈保证。

上述 source 数学 IVP、编译后 COMSOL 输出和物理轨迹仍是不同对象。物理初态/观测/执行器误差、编译方程同一性、一般 42 系数或未知目标 KAM 迁移，以及一般复值网络优势尚未证明；完整研究目标仍未完成。
